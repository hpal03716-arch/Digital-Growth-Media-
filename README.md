# Digital Growth Media – Website

Single-file website (`index.html`) for Digital Growth Media.

- Open `index.html` in a browser, or use the Live Server extension in Codespaces.
- Deploy free with GitHub Pages (Settings > Pages > Branch `main` / root) or Vercel.
- Client work section includes a Video Work column (videos play from Google Drive, so the Drive files must be shared as "Anyone with the link").
